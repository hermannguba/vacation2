# Красный Огорок · семейный гид

Небольшой сайт-гид по отпуску в деревне **Красный Огорок** (Киржачский район, Владимирская область) и однодневной поездке в **Суздаль** с ребёнком около 3 лет.

## Что внутри

- **Главная** — активности на базе и рядом (лес, бассейн, мангал, Киржач), рестораны и кафе с хорошими оценками / семейным форматом.
- **Суздаль** — что посмотреть с малышом и где вкусно поесть (сводка по популярным местам).

Рейтинги и меню могут меняться — перед визитом лучше свериться с актуальными картами и сайтами заведений.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на [http://127.0.0.1:4721](http://127.0.0.1:4721).

Сборка:

```bash
npm run build
npm run preview
```

## Стек

Vite · React · TypeScript · Tailwind CSS · React Router
